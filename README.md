# Kumo ☁️

Kumo store website — toys, figures, cars and cute finds from China, prices in taka.

- Shop settings (WhatsApp, bKash, Facebook link): top of `src/App.jsx`
- Price rules (yuan rate, cargo per kg, profit): `src/data/pricing.js`
- Products: `src/data/products.js`, or a Google Sheet (link goes in `src/data/useProducts.js`)
